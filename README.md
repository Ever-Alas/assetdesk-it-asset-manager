# AssetDesk — IT Asset Manager

A lightweight IT asset inventory web application built with vanilla HTML, CSS and JavaScript.

## Project files

The application is currently located in [`it-asset-manager/`](./it-asset-manager/).

- [Open the application source](./it-asset-manager/index.html)
- [Full documentation](./it-asset-manager/README.md)
- [Testing checklist](./TESTING.md)

## Run it

1. Clone or download this repository.
2. Open the `it-asset-manager` directory.
3. Launch `index.html` with a local server (such as VS Code Live Server) or a compatible browser preview.

No backend or account is required. Inventory data is stored in your browser's localStorage, so it is **not synchronized between computers or browsers**. Use the JSON export/import feature to transfer demo data manually.

## What it can do

- Add, edit, remove and filter equipment
- Track assignment and lifecycle status
- Export inventory as CSV
- Back up and restore inventory with JSON
- Reject duplicate asset tags

**Demo only:** Use fictitious asset and staff information; do not upload employer or customer records.
